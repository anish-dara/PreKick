Key design decisions
Memory key

Memory is keyed per person, not per project. Tom's record grows across every engagement — projects are disposable, people aren't.

Autonomous ops

Phases 2 and 4 require zero human input. The agent reads before calling and writes after — both logged live to the Memory Log panel.

Platform-agnostic

Output is structured data — stakeholders, risks, agenda, success criteria — ready to push to any PM tool without platform lock-in.
