01
DEAL CLOSE — PROJECT SETUP
PM
Deal closes in CRM. PM creates project in PreKick.
Claude
Upload SOW — Claude extracts scope, timeline, and deliverables via POST /api/extract.
PM
Add stakeholders: Sponsor, IT Lead, Project Lead, Finance.
02
AUTONOMOUS RECALL — no human prompt
HYDRA READ
Backend
GET /api/stakeholder-history fires automatically for each stakeholder on project setup.
HydraDB
Embedding similarity search retrieves prior records for each person.
HydraDB
1 prior interview found for Tom Becker — full transcript and extracted concerns returned.
UI
[HYDRA READ] stakeholder=Tom Becker → 1 prior interview retrieved
03
MEMORY-INFORMED VOICE CALL
Backend + Claude
POST /api/next-question with prior_history — ElevenLabs dynamic variables set before dial.
ElevenLabs
Agent dials stakeholder. Judge receives live phone call.
Agent
"Hi Tom, last time we spoke the Salesforce integration was your biggest concern — where does that stand now?"
ElevenLabs + Claude
Gemini 2.5 Flash handles in-call latency. Claude generates memory-informed follow-up questions.
04
AUTONOMOUS WRITE — no human prompt
HYDRA WRITE
ElevenLabs
Call ends. Webhook posts full transcript to POST /api/call-webhook.
Claude
Extracts concerns: Salesforce integration, timeline risk, scope consultation gap.
Nebius
Vector embedding generated for future similarity retrieval.
HydraDB
New stakeholder_interview record appended to Tom's persistent record. [HYDRA WRITE] stakeholder=Tom Becker, interview_id=ib_9f3a2c1d...
05
CONTINUITY-AWARE SYNTHESIS
HYDRA READ
Backend
POST /api/conflict-map loads all transcripts + each stakeholder's HydraDB history.
Claude
Cross-stakeholder conflict map generated + "Continuing from last time" objects per returning stakeholder.
Frontend
Continuity cards rendered: prior_quote · current_quote · status: persisting | resolved | escalated | new
Frontend
Tom's card — Salesforce integration: status=ongoing. Prior: "nightmare." Current: "still unresolved."
